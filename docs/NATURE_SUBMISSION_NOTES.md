## Important pre-submission issues

1. **Length.** Nature Articles are much shorter than this 23-page manuscript.
   The current file is a complete Nature-style manuscript, not a journal-ready
   Article at final length. It should be shortened (main text, Methods,
   references, tables) before submission.
2. **Title/framing.** “Emerging functional consciousness” is a strong claim.
   The text qualifies it and reports the M4 failure, but Nature editors/reviewers
   may still regard the framing as overreach. Consider “functional
   self-organization” or “incipient functional self-representation” if the
   editor asks for a more conservative title.
3. **Mechanism limits.** The mirror inspection is partly rule-based and the
   environment is a 2D feature-level simulation. The manuscript states this
   explicitly; do not describe it as a photorealistic physical mirror.
4. **SelfModel update.** M6 stored memory and restored a checkpoint, but a
   SelfModel parameter update and delayed reuse were not demonstrated. The text
   says so.
5. **Affect-to-action.** AFFECT-02 did not establish a complete
   affect-to-action pathway. The text says so.
6. **arXiv link.** After arXiv assignment, add the arXiv ID/DOI to the Nature
   title page and cover letter. The current Nature file does not invent one.
7. **Data/code.** Nature will require a public repository or a concrete
   accession; “on reasonable request” is not sufficient for final submission.
8. **Figure permissions.** Figure 1 is generated locally; no third-party
   permission is needed for the diagram itself.
